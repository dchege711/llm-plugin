# Bionic

A collection of skills and instructions to augment how I use LLMs. Not meant for
public consumption as I heavily customize these based on what works for *me*. I
also copy and tweak a lot of content from random repos and blogs, and so keeping
this repo private qualifies it as fair use.

## Usage

Kick start the installation using the GitHub CLI, e.g.,

```shell
gh skill install dchege711/bionic socratic-tutor
```

... and then follow the interactive instructions.
